AI integration checklist

Prioritized controls derived from a real audit; business-specific instructions removed.

Sanitized from a real production audit. Identifying business information and competitor names were removed; retained numeric engineering metrics are unchanged unless explicitly noted.

Evidence foundation

1. Make the entity explicit

  1. Publish a consistent organization identity in visible copy and structured data.
  2. Connect services, locations and proof points to that entity.
  3. Keep names and identifiers consistent across first-party profiles.
  4. Record source URLs and timestamps for every implementation claim.

Acceptance check: each published fact resolves to a current first-party source.

Content coverage

2. Close measured query gaps

  1. Map priority query types to relevant service or decision pages.
  2. Answer urgent and problem-based intents directly and factually.
  3. Add comparison evidence without unverified superlatives.
  4. Measure the same query battery again after implementation.

Acceptance check: content changes are traceable to query-type evidence and can be re-audited.

Release gate

3. Validate before publishing

  1. Run schema and link checks.
  2. Review every claim status; reject unsupported or forbidden wording.
  3. Preserve the package hash, manifest and validation result.
  4. Keep signing-key verification separate from factual claim validation.
